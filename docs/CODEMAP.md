# Code map: `index.html`

Moved here from `AGENTS.md` §5 (28 Nov 2026) so the brief every session reads stays short. Search this file for the area you are touching rather than reading it whole. **Keep it current:** a PR that adds or moves a section, a key function or table, or a storage key updates its row here.

Everything lives in one file (about 21,600 lines): CSS, then markup, then one big script inside an IIFE. The sections appear in this order, each marked by a `/* ------- name ------- */` comment.
